# NextShift

NextShift helps everyday workers turn their existing job experience into practical AI skills.

## Mission
AI should make experienced workers more capable, not make them feel obsolete. NextShift teaches useful AI skills in plain English through short lessons, quizzes, real workplace practice, and a free 7-day plan.

## Current build
- Mobile-first web app
- Three beginner lessons with quizzes
- A lesson is completed only after the correct quiz answer
- 7-day practical AI plan with local progress
- AI Practice flow that builds a strong work prompt and is ready for a secure `/api/coach` provider endpoint
- No paid service required for the static learning experience

## Next step
Connect the secure AI provider endpoint and deploy the web app. Never put an AI API key in browser-side JavaScript.
